## Model 1 — Fall Risk ConvLSTM

| Field | Value |
|-------|-------|
| **Model name** | `fall_risk_model` |
| **Serves** | **Module 1 — Pressure Mat** (Board 1) |
| **Hardware** | ESP32 + CD4067 16-channel analog mux + 74HC595 shift register + 12×6 Velostat pressure grid |
| **Architecture** | `Sequential: Reshape(20,12,6,1) → ConvLSTM2D(8, 3×3, padding=same, tanh) → Flatten → Dense(16, relu) → Dense(3, softmax)` |
| **Classification classes** | `0 = normal`, `1 = unsteady`, `2 = fall` |
| **Input shape** | `(1, 20, 12, 6, 1)` — 20 timesteps of 12×6 pressure grid frames (72 ADC values per frame, uint12: 0–4095) |
| **Normalization** | `X / 4095.0` (ADC range → [0, 1]) |
| **Optimizer** | Adam |
| **Loss** | `sparse_categorical_crossentropy` |
| **Training epochs** | 12, batch_size=32, validation_split=0.15, EarlyStopping(patience=3) |
| **Training data** | `data/synthetic/mat_synth_X.npy` + `mat_synth_y.npy` (generated by `datasets/gen_mat_data.py`) |
| **Target accuracy** | ≥ 0.85 on 15% synthetic hold-out |
| **Reported accuracy** | **1.000** (100% on synthetic test set — see [Performance](#1-fall-risk-convlstm-performance)) |

> **Grid upgrade note (12×6 = 72 cells):** the wire contract, generator and
> fusion rules now use the 12×6 grid. The shipped `fall_risk_model.h5` was
> trained on the old 16×4 grid; until it is retrained from
> `data/synthetic/mat_synth_*.npy` (regenerate with `datasets/gen_mat_data.py`,
> then `training/train_fall_convlstm.py`), the model's `predict()` throws a
> shape mismatch that `fusion_engine.py` swallows, so live risk falls back to
> the rule-based path. Same status 0/1/2 classes and 20-frame sequences.

### Artifact Files

| Artifact | Path | Status |
|----------|------|--------|
| Keras model | `models/fall_risk_model.h5` | ✅ Present |
| TFLite model | `models/fall_risk_model.tflite` | ✅ Present |
| C header (firmware) | `firmware/shared/model_data/fall_risk_model_model_data.h` | ✅ 34.4 KB |

### Deployment

- **Backend:** Loaded by `fusion_engine.py` → `load_optional_models()` via `tf.keras.models.load_model()`. Wrapped in a closure that reshapes frames to `(1, 20, 12, 6, 1)` (post-retrain) and runs `model.predict()`. Called when ≥ 20 mat frames accumulated.
- **Firmware:** C header auto-generated from TFLite conversion; included at compile time for potential on-device inference (currently not embedded in Board 1 firmware — inference runs on laptop).
- **Fallback:** Rule-based `mat_sustained_high_pressure()` + `mat_centroid_jump()` in `alert_rules.py` provide the same `fall_risk` flag independently of the model.

## Rule-Based Detection (No Model — Physics Heuristics)

These run inside `backend/alert_rules.py` and `backend/fusion_engine.py` without any trained model. They provide immediate danger detection while waiting for real training data.

| Rule | Module | Trigger | Severity | Flag Raised |
|------|--------|---------|----------|-------------|
| `mat_sustained_high_pressure()` | 1 (Mat) | Total pressure > 60,000 for ≥ 2 seconds | High | `fall_risk` |
| `mat_centroid_jump()` | 1 (Mat) | CoP shifts > 5 cells between frames | High | `fall_risk` |
| `radar_possible_collapse()` | 2 (Radar) | Motionless + presence for ≥ 15 seconds | High | `possible_collapse` |
| `acoustic_thud_confirmed()` | 4 (Audio) | Impact thud label + radar confirms presence | High | `acoustic_distress` |
| `acoustic_sustained_cry()` | 4 (Audio) | Speech/cry label sustained ≥ 5 seconds | High | `acoustic_distress` |
| `tof_collapse_trigger()` | 5 (ToF) | Board 5 reports ToF collapse posture | High | `tof_collapse` |
| `scald_shutoff()` | 5 (Thermal) | Hot water flow + no user pressure present | Critical | `thermal_freeze` → scald shutoff |
| `toilet_uti_flag()` | 3 (Toilet) | RF classifies `uti_risk` for 3+ consecutive readings | Medium | `toilet_biomarker` |
| `toilet_dehydration_flag()` | 3 (Toilet) | RF classifies `dehydration_risk` 3+ times in 24h | Medium | `toilet_biomarker` |

## Fusion Engine — Weighted Ensemble

The `FusionEngine.tick()` method combines all module flags into a single risk score:

| Flag | Weight | Source |
|------|--------|--------|
| `fall_risk` | 26 | Model 1 (ConvLSTM) + rules |
| `possible_collapse` | 22 | Radar rules |
| `acoustic_distress` | 18 | Audio rules |
| `tof_collapse` | 18 | Board 5 rules |
| `thermal_freeze` | 20 | Model 2 (CNN+LSTM) + rules |
| `toilet_biomarker` | 8 | Model 3 (RF) |
| `routine_anomaly` | 8 | Model 6 (IsolationForest) |

**Score computation:** `score = max(effective_weight_sum × 100, previous_score × 0.9)`  
**Bands:** normal (< 30) → watch (30–60) → high (> 60)  
**State machine:** resolved → voice_pending (High triggers voice triage) → alerting (no response/help) → resolved (auto-decay)
